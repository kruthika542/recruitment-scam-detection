# Dataset Documentation

This folder contains documentation and instructions for the datasets used in the Multilingual Recruitment Scam Detection project.

## Datasets
- EMSCAD: Fake job posting detection.
- Scam Dialogue: General scam conversation analysis.

## Data Preparation
- Inspect missing values and duplicates.
- Verify labels and language distribution.
- Keep recruitment-related conversations separate from general scam conversations.
- Do not upload datasets without checking their licenses.

## Privacy
Do not upload private conversations or personal information.
